Photon
Terminal Code review Workspace Agents Lean GitHub

The terminal is where the work happens.

Photon puts it at the center, then builds the editor, code review and your AI agents around it.

brew tap heapworks-in/photon && brew install photon

macOS on Apple silicon. Alpha: fast and usable every day, with some rough edges.

Terminal

A terminal that remembers what happened.

Every command and its output become one block. You never scroll back through noise to find what you need.

Every command is a block

A block shows where the command ran, on which branch, how long it took, and whether it worked. Right-click a block to copy its command or its output, or to run it again.

The input behaves like an editor

Select text with the mouse, undo, and write commands over several lines. ↑ walks your history, and ctrl R searches it across every project. Tab completion comes from your own zsh setup.

Test runs you can act on

cargo test, pytest, jest and friends are summarised as passed and failed. Re-run only the failures, and press F8 to jump to each error.

git status, in place

Stage, diff or discard each file right where git status listed it. In git log, cmd-click a commit hash to open it.

Output that becomes a table

JSON, kubectl get and docker ps output can open as a table or as JSON, or be copied as CSV.

It tells you when the build is done

When a long build finishes while Photon is in the background, it sends a macOS notification. Click it to land back on that block. Cmd-click src/main.rs:42 in any output to open that line beside the terminal.

Code review

Pull requests that read like code.

Photon arranges a pull request in the order you'd want to read it, and shows you what each change touches.

What needs your review

The Pull requests panel lists what's waiting on you for the repositories in this window, with checks, unresolved threads and new commits since your review.

A review map in reading order

The change is grouped into steps: functions that get called come before the code that calls them, and tests come last.

Each change with its surroundings

Every change shows the code it touches: the functions it calls and the code that calls it.

Callers the PR forgot

The impact panel lists every caller of the function under your cursor and flags the ones the pull request didn't update.

Comment on any line

Not only the lines in the diff. Drafts save as you type and survive restarts.

Changes since your review

See only what the author changed after your last review, even if they rebased.

Run it locally, safely

Run locally opens the pull request in a separate copy of the repository, so your own branch and stash are never touched. PR checkouts never run git hooks, and the PR stays in Restricted Mode, with no language servers, until you click Trust. Photon asks again when the author pushes. Your GitHub login stays with gh; Photon never reads or stores tokens.

Workspace

Every project, one window.

Projects and pull request reviews open as tabs in the window you're already in.

Projects as tabs

Each extra project uses about 67 MB less memory than a separate window. Drag tabs to reorder them, and right-click to close or move one to its own window. Tabs come back in order after a restart.

  • ctrl shift ] and ctrl shift [ switch tabs
  • ctrl shift T opens a new tab, ctrl shift W closes one
  • cmd O or ctrl R opens a project as a new tab
Agents

Your agents, on your plans.

Photon doesn't sell you an AI subscription. It connects to the coding agents you already pay for.

Bring Claude Code, Devin, or any ACP agent

Any agent that supports the Agent Client Protocol works. The agent runs as you, and Photon has no server in between.

Lean on purpose

Quick to open, quiet on the wire.

Cold start under 300 ms, about 130 MB at idle, no network calls at startup, no account, and telemetry off for good.

Make it yours

Change the look in one step.

Font styles change the editor, menus and terminal together. Photon Black is the default theme.

Open the command palette with cmd shift P and choose Photon: Use Mono / Hack / Menlo / Monaco font style. Switch themes with cmd K cmd T. "terminal": { "blocks": false } restores the classic terminal, and "smart_blocks": false keeps blocks without the extra actions.
