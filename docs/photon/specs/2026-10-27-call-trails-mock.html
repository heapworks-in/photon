Call Trails, redesigned

One panel, two views of the same trail: a list that shows how each function is called (the call-site lines), and a map that shows the shape at a glance. Selecting anything shows the trail back to the root as a breadcrumb. All data comes from the language server, live and local; no AI needed. An optional "Explain this trail" can ask your own agent, Devin-style.

Why each part is thereThe header says what you're looking at and how big it is. The call-site lines answer "how is it called?" without leaving the panel. The breadcrumb answers "how did I get here?".
Signals, not noiseEntry points (main, handlers), tests and recursion are marked; "×2" counts call sites. No "No callers" rows: a leaf is just a leaf. In a PR review, functions the PR changed are flagged.
Stays lean and Zed-likeBuilt from Zed's list, indent guides, chips and colours; everything loads lazily from the language server as you expand. The map is drawn by Photon (no web view). "Explain this trail" is optional and uses your own agent.
